\section{Введение}
Данный файл служит для тестирования компиляции русскоязычного LaTeX-документа с использованием XeLaTeX и polyglossia.

\begin{definition}[Тестовое определение]
Пусть $f \colon \II^s \to \RR$ --- интегрируемая функция.
\end{definition}

\begin{theorem}[Тестовая теорема]
Интеграл $I(f) = \int_{\II^s} f(\vx) \, d\vx$ может быть аппроксимирован методом квази-Монте-Карло.
\end{theorem}
